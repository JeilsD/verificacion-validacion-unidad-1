# Unidad 1: revisión estática del módulo de descuentos

Actividad académica individual para revisar requisitos y aplicar ESLint al módulo JavaScript de descuentos.

## Estructura

- `src/`: código fuente.
- `docs/`: requisitos, checklist y registro de revisión.
- `evidencias/`: salidas reales de ESLint.
- `eslint.config.cjs`: reglas de análisis.
- `package.json`: dependencias y comando de lint.

## Uso

Instala las dependencias con `npm install`.
Ejecuta la revisión con `npm run lint`.

## Alcance

Se corrigieron los patrones señalados por ESLint. No se ejecutaron pruebas funcionales. Las reglas sobre descuentos VIP, promociones, entradas y redondeo quedan pendientes de confirmación.

Debido al desarrollo individual de la actividad, se realizó una inspección estructurada del código con registro de hallazgos, evidencias y decisiones. No se contó con un revisor externo.
